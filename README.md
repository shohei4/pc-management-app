# PC管理アプリ
## 開発経緯
* 依頼されたものを作る経験をしたいと考え、事業所のスタッフからの依頼で貸出用のPCを管理するアプリを作成
## 開発期間
* ３か月ほど（就職活動の傍らで作成）
## 開発環境
* Windows 11
* Eclipse 2025-12
* Java SE-21
* PostgreSQL 17

## アプリの機能一覧
* ログイン・ログアウト機能
* PC情報の登録・更新・削除
* PC情報の一覧管理

## 工夫した点
**技術・設計**
* 中間テーブルを使用してPC情報とソフトウェアの情報を管理し、拡張性を高めた
* 業務例外を型で分類する階層構造を採用した
RuntimeException  
 └─ ApplicationException   … ステータスとエラーコードを持つ基底クラス
    └─ ConflictException  … データ競合(409)の分類  
       ├─ DuplicateUsernameException
       └─ DuplicatePcNumberException  
  * 例外の型で原因を特定でき、`ConflictException` でまとめて捕捉できる
  * フォーム画面では入力値とエラーを再表示する必要があるため、
  コントローラーで `try-catch` + `rejectValue` により処理している
  (当初は `@ControllerAdvice` を試したが、`BindingResult` や入力済みフォームを
  引き継げないため、この方式に変更した)
**機能**
* 半角・全角を検知し、数字の場合は半角にして番号を`%03d`で3桁ゼロ埋め表示するようにした
* 入力画面での初期値の設定によりユーザービリティを向上させた。
* 一覧表示を利用者属性ごとにグループ化して表示することで、見やすくした
